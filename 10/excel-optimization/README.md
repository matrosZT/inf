# Інтерактивний тренажер: Розв'язування оптимізаційних задач (10 клас)

Веб-додаток з інформатики для 10 класу за програмою та підручником **О. О. Бондаренко**, адаптований для смартфонів, планшетів і ПК, повністю готовий до публікації на **GitHub Pages**.

## Можливості тренажера
- **Реєстрація учня:** введення ПІБ та вибір класу (`10-А`, `10-Б`, `10-В`, `10-Г`, `10-Д`, `10-Ж`, `10-К`).
- **Етап 1 (Побудова математичної моделі):** підтримка як перетягування (Drag-and-Drop на ПК), так і вибору дотиком (Tap-to-Place на смартфонах).
- **Етап 2 (Інтерактивна симуляція виробництва):** зміна параметрів випуску ($x, y$), візуалізація витрати ресурсів та графік області допустимих розв'язків (ОДР) на Canvas у реальному часі.
- **Етап 3 (Симуляція «Пошук розв'язку» / Solver):** налаштування цільової клітинки, напряму оптимізації, клітинок змінних та обмежень.
- **Підсумковий звіт та експорт у PDF:** фіксація всіх спроб, проміжних результатів симуляції, часу виконання та завантаження PDF-документа з кирилицею.

## Як опублікувати на GitHub Pages
1. Створіть новий публічний репозиторій на GitHub (наприклад, `optimization-10-class`).
2. Завантажте файли `index.html`, `.nojekyll` та `README.md` у корінь репозиторію.
3. Перейдіть у **Settings → Pages**.
4. У розділі **Build and deployment** оберіть Source: **Deploy from a branch**, гілку `main` та папку `/ (root)`, натисніть **Save**.
5. Через 1–2 хвилини тренажер буде доступний за посиланням `https://<ваш-логін>.github.io/<назва-репозиторію>/`.
