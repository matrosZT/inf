Теоретична довідка: будова лінійної програми та блок-схема

Лінійний алгоритм — це алгоритм, у якому всі команди виконуються послідовно одна за одною, зверху вниз, без розгалужень і повторень.

  • Овал у блок-схемі позначає Початок або Кінець алгоритму.
  • Паралелограм використовується для Введення даних (input()) та Виведення результатів (print()).
  • Прямокутник позначає Обчислення (присвоєння значень змінним).
  • У Python операція ділення / завжди повертає дробове число (float), // — цілу частину від ділення, а % — остачу від ділення.

2. Обмін значень двох змінних через третю змінну tmp

0 / 2 бали

Чому не можна написати просто a = b; b = a?

Команда присвоєння a = b копіює значення зі змінної b у змінну a, при цьому старе значення a стирається назавжди. Якщо після цього виконати b = a, обидві змінні матимуть однакове значення.

Щоб не загубити дані, використовують «запасну» третю змінну tmp (від англ. temporary — тимчасовий):
tmp = a → a = b → b = tmp.

Задай початкові числа для a та b і виконай правильну послідовність команд обміну за допомогою кнопок нижче, щоб у комірці a опинилося значення b, а в b — початкове значення a.

3. Збери програму «Середній бал» у правильному порядку

0 / 3 бали

Порядок дій та пріоритет операцій у Python

Будь-яка задача розв'язується у чіткому порядку: 1) Введення даних → 2) Обчислення за формулою → 3) Виведення відповіді.

Увага на дужки! У виразі 10 + 11 + 12 / 3 Python спочатку поділить 12 / 3 = 4.0, а потім додасть 10 + 11 (вийде 25.0). Щоб знайти середнє арифметичне, чисельник обов'язково беруть у дужки: (a + b + c) / 3.

Перетягни рядки коду з лівої колонки у слоти правої колонки (на смартфоні можна торкнутися рядка зліва, а потім — потрібного слота справа). Зайвий рядок із помилкою пріоритету залиш у банку!

4. Встанови відповідність між задачею та формулою Python

Шпаргалка формул до Уроку 10

  • x% від суми: suma * x / 100 (наприклад, 25% від 1200 → 1200 * 25 / 100 = 300.0).
  • Сантиметри у метри: sm / 100 (175 см → 1.75 м).
  • Повні години з хвилин: hv // 60 (цілочисельне ділення).
  • Залишок хвилин: hv % 60 (остача від ділення).

5. Доповни код Python для переведення секунд у години, хвилини та секунди

0 / 3 бали

Підказка до задачі «Стрім» (Категорія 3)

В одній годині 3600 секунд (60 × 60). В одній хвилині — 60 секунд.

  • Повні години знаходимо цілочисельним діленням: god = sec // 3600.
  • Залишок секунд після виділення годин: zal_sec = sec % 3600.
  • Із цього залишку знаходимо повні хвилини: hv = zal_sec // 60.
  • І останні секунди: s = zal_sec % 60.
