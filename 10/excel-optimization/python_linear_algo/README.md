# Інтерактивний тренажер: Лінійні алгоритми в Python (10 клас)

Цей репозиторій містить автономну інтерактивну вебсторінку, створену за матеріалами **Уроку 10 (Інформатика, 10 клас)**.

## Можливості тренажера
1. **Симуляція №1 (Конвеєр лінійного алгоритму)** — покрокова візуалізація блок-схеми та стану змінних у пам'яті ПК для 4 задач уроку.
2. **Симуляція №2 (Обмін значень змінних через `tmp`)** — інтерактивна модель роботи з комірками пам'яті та демонстрація помилки затирання значення без третьої змінної.
3. **Drag & Drop №1** — складання програми «Середній бал» у правильному порядку (з підтримкою сенсорних екранів смартфонів).
4. **Drag & Drop №2** — зіставлення умов задач із формулами мовою Python (`//`, `%`, `/`).
5. **Практика кодування** — інтерактивне доповнення коду задачі «Стрім» із миттєвим тестуванням на довільній кількості секунд.
6. **Кнопки «Дізнайся більше»** — вбудовані теоретичні довідки до кожного завдання.
7. **Генератор PDF-звіту** — фіксація всіх спроб, часу роботи, проміжних результатів і балів учня з можливістю завантаження `.pdf` файлу на комп'ютер чи смартфон.

## Як опублікувати на GitHub Pages
1. Створіть новий репозиторій на GitHub (наприклад, `python-linear-algorithms-10`).
2. Завантажте файл `index.html` (та `README.md`) у корінь репозиторію.
3. Перейдіть у **Settings → Pages**, у розділі **Source** виберіть гілку `main` (`/root`) та натисніть **Save**.
4. Через 1–2 хвилини інтерактивний урок буде доступний за посиланням GitHub Pages.
